# Findings

## Research Notes
- **UI Inspiration**: Reviewed two mockups from the `desgin insp` folder.
  - Mockup 1: Classic SaaS Look, sidebar with multiple navigation links. Board columns: "In progress", "To-Do", "Complete". Cards have dates, priority flag (High/Normal/Low), assignee avatars, attachment counts, and comment counts. Drag indicator is a dashed box.
  - Mockup 2: Modern rounded aesthetic. Main area has project headers (e.g., "Mobile App for ios"). Board columns: "To Do", "In Progress", "Need Review", "Completed". Cards have a category label (e.g., "UI Design"), urgency pill, description snippet, subtask progress (e.g., 0/8), plus avatars and counts.
  - **Selected Direction**: We will incorporate elements of both, leaning towards the structured columns and detailed card elements (priority, dates, avatars, checklist progress) for a rich Kanban experience.
